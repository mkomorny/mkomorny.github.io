# DigiDreamWeaver Labs | Official Website

This repository hosts the official landing page and technical architecture showcase for **DigiDreamWeaver Labs** ([https://mkomorny.github.io](https://mkomorny.github.io)), founded and engineered by **Miranda Komorny**.

### Technical Highlights
- **Foundation Intelligence**: Built natively for Anthropic Claude 3.5 Sonnet & Claude 3.5 Haiku.
- **Model Context Protocol (MCP)**: Native integration connecting Claude directly into Digital Audio Workstations (Ableton Live 12) and WebAudio DSP runtimes.
- **Prompt Caching Economics**: Implements ephemeral prompt caching across large audio manuals and music theory corpora to slash multi-turn latency and token overhead.
- **Local-First Architecture**: Zero cloud audio transmission; studio DSP executes client-side via WebAudio and WebAssembly (WASM).
